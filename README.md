## Features

### Frontend

- Responsive design for mobile, tablet, and desktop
- Homepage with featured products, promotional banners, and CTAs
- Product catalog with category filters, search, and sorting options
- Product detail pages with images, description, price, stock status, and reviews
- Shopping cart with add/remove/update quantity functionality and cart persistence
- Multi-step checkout workflow with Stripe payment simulation and order confirmation
- User authentication: register, login, password reset
- Smooth animations, hover effects, and interactive UI elements
- SEO-friendly page metadata and structured data

### Backend

- Node.js with Express.js RESTful API
- MongoDB database with Mongoose ODM
- User management with JWT authentication and bcrypt password hashing
- Product management CRUD for admin users
- Order management, including status tracking and history
- Coupon/discount system
- Stripe sandbox payment integration with webhook handling
- Admin dashboard analytics with sales data, top products, and users
